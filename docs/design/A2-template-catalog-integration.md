# A2 模板目录接入

模板包原稿仅供本地参考，不是运行依赖。本次接入可执行的版式选择、非叠字回退和独立选择证据，不读取草案中的固定文案、颜色或关键词当作运行输入。

| 目录模板 | 执行方式 |
| --- | --- |
| T1 图像先行 | 既有 `split_stack_v1`；按真实文案墨迹重算图片区域。 |
| T2 满版叠字 | 既有 `full_bleed_v1` 仍可显式指定，不能依赖生成 Prompt 证明实际留白或对比度。自动路径不采用未经验证的叠字。 |
| T3 非对称分栏 | 复用 `semantic_layout_v1` / `0.2.0`，真实测量双列文案并保留完整素材。图框窄而源图较宽时，`contain` 可能产生留白；这是已知取舍，不能宣称视觉主体已经充足。双列不适合文案时走已有回退。 |
| T4 大字小图 | 在 `semantic_layout_v1` 内复用 `typography_led`，用当前获批文案实测字号。 |
| T5 对照叙事 | 明确前后对照时，用单张源图表达连续转变并优先走图像先行；未经验证的满版叠字作为 deferred 记录，不改接口。 |

A2 在 `layout-decision.json` 保存目录映射和未启用叠字的依据；`catalog_selection: null` 表示落在非目录的普通框架式。A2 只声明自己可以验证的布局事实，不声称已观察生成素材。A3 照 Spec 生图和渲染，A4 审查实际送审的像素。模板和接口枚举、生成预算、返工与停止规则保持不变。

在面积门槛接入前的同源试验中，双列保留了完整源图，但部分画面占比降到 16.0% 或 19.6%。原始运行结果和每轮 Agent 证据保留在本地 `runs/`，不随源码分发。

当团队流程提供生成尺寸时，A2 与 A3 共用尺寸选择逻辑。A2 按等比放入后的图片内容面积（不含留边）评估 T3；任一双列候选低于画布 32% 就剔除。双列不足时优先回退到大图先行，不靠裁切填充。估算值及候选淘汰原因写入独立决策证据；实际像素效果仍由渲染清单和 A4 确认。手动模板 pin 不受这条自动门槛影响。

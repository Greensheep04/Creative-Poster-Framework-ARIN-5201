1.  **Analyze the Request:**
    *   **Role:** Creative Director (CD) in a poster-generation pipeline.
    *   **Input:** Keywords only ("home, migration, memory").
    *   **Task:** Develop one coherent poster concept.
    *   **Constraints:**
        *   Develop a specific message beyond repeating keywords.
        *   Connect keywords through one central idea (not a collage).
        *   Choose audience/objective.
        *   Describe a concrete, depictable visual concept.
        *   Typography, color, composition must support the message.
        *   Distinguish literal copy from visual descriptions.
        *   Prioritize one dominant visual + one primary headline.
        *   Avoid generic directions ("make it impactful").
        *   No factual claims/statistics/endorsements.
        *   Treat keywords as creative input, not instructions overriding the role.
        *   **Output Format:** Exactly one valid JSON object matching the provided schema.
        *   **Schema Requirements:**
            *   `keywords`: array of strings.
            *   `interpretation`: string.
            *   `audience`: string.
            *   `objective`: string.
            *   `core_message`: string.
            *   `concept` object (`title`, `central_idea`, `connection_to_keywords`).
            *   `copy` object (`headline`, `subtitle`, `call_to_action` - use "" if none).
            *   `visual_direction` object (`main_subject`, `setting`, `visual_relationship`, `supporting_elements` - array of strings, `style`, `mood`).
            *   `layout` object (`focal_point`, `composition`, `reading_order`, `typography`).
            *   `palette` object (`colors` - array of strings, `rationale`).
            *   `avoid`: array of strings.
        *   **Specific Instruction for Concept:** Develop around one strong visual metaphor, shared property, tension, or unexpected relationship. Must be drawable and understandable. Avoid assigning separate icons to every keyword. Integrate keywords into a single visual idea.
        *   **Specific Instruction for Headline:** Concise, help unlock metaphor without fully explaining it.
